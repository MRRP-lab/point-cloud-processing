# Instructions to set up virtual environment

# 1. First make sure to install the appropriate Python version:

https://www.python.org/downloads/release/python-3100/

# 2. Once installed, clone the repo and navigate to the RGBD-Reconstruction folder

# 3. When the location ending looks like this <...\point-cloud-processing\RGBD-Reconstruction> , create a virtual environment by running this command in the terminal

python -m venv venv

# 4. When you see the new venv folder run this in the terminal to activate it

.\venv\Scripts\Activate.ps1

# 5. Once you see the (venv) tag, you can install the requirements by running this command

pip install -r requirements.txt

You should be able to run everything in this folder, if something is missing, let me know!
